# goa-console — DIY 24+ channel line-level mixing console

Owner: Ruslan. Answer in English. Expert electronics hobbyist (KiCad, analog audio) — be technical, no hand-holding.

## PCB scope
Component placement only. Ruslan does all copper routing in KiCad. Deliver no tracks,
vias or copper zones; do not autoroute, pour grounds or add stitching/escape vias.
Keep footprint pads and the net-tie's internal copper. See `AGENTS.md`.

## What this is
A Soundcraft-Delta-style console for mixing hardware synths (goa trance).
Line level only. One identical PCB per channel, joined by a 34-way IDC ribbon "motherloom".
Channel = a Soundcraft Delta Theatre input without the mic stage (decided 2026-10-22): line gain,
Ø, HPF, 4-band EQ, post-EQ insert, ON, PFL, aux 1-6 with PRE switches, pan + PAN switch, routing,
direct out. Spec in progress: `delta_clone_comparison.md`; the strip spec/schematic are the old
no-EQ channel until v4.0.

## Files
- `channel_strip.kicad_sch` / `.kicad_pro` — channel strip schematic (KiCad 7 file format, opens in KiCad 10; A1, label-connected).
  GENERATED by `tools/gen.py` — edit the generator (netlist is in the `P(...)` calls), then regenerate.
- `master.kicad_sch` / `.kicad_pro` — master section (one User-size sheet, ~1.0 x 2.3 m, 1059 parts).
  GENERATED by `tools/gen_master.py` from master_section_spec.md (helper functions per circuit;
  refs auto-assigned, dual op-amps/comparators allocated unit by unit with their decoupling).
  Both generators use the shared builder `tools/schgen.py`. Same loop with `master` in place of
  `channel_strip` (`tools/gen_master.py master.kicad_sch`). Exports: master.net/.pdf/_BOM.csv.
- `goa-console.kicad_sym` + `sym-lib-table` — project symbols (DRV134).
- `channel_strip.kicad_pcb` — strip PCB, 38 × 480 mm, component placement only:
  no tracks, vias or copper zones. Rebuild with `tools/build_strip_pcb.sh [output.kicad_pcb]`
  or run `tools/place_strip.py` with KiCad's Python:
  `/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3 tools/place_strip.py channel_strip.net channel_strip.kicad_pcb`
  Re-running the generator overwrites unrouted placement edits. It refuses to overwrite
  an existing board containing tracks, vias or zones; use a separate output for later placement work.
  Check with `$KC pcb drc --schematic-parity --severity-all channel_strip.kicad_pcb`;
  unconnected items are expected at the placement stage and are not an instruction to route.
  Schematic UUIDs are deterministic (schgen.py), so the footprint-symbol link survives regeneration.
- `tools/verify.py` — checks KiCad's exported netlist against `channel_strip_intended.json`.
  Regenerate + verify loop:
  ```
  KC=/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli   # macOS, KiCad 10.0.7
  .venv/bin/python tools/gen.py channel_strip.kicad_sch
  $KC sch export netlist -o channel_strip.net channel_strip.kicad_sch
  .venv/bin/python tools/verify.py channel_strip.net channel_strip_intended.json
  python3 tools/check_fp.py channel_strip.net                # pins vs footprint pads
  $KC sch erc --severity-all channel_strip.kicad_sch
  $KC sch export pdf -o channel_strip.pdf channel_strip.kicad_sch
  ```
  BOM: `$KC sch export bom -o channel_strip_BOM.csv --fields '${QUANTITY},Value,Footprint,MPN,Reference' --labels 'Qty,Value,Footprint,MPN,References' --group-by 'Value,Footprint,MPN' --ref-delimiter ' ' --ref-range-delimiter '' --string-delimiter '' channel_strip.kicad_sch`
  `.venv/` (gitignored) holds kiutils 1.4.8. gen.py finds the symbol libs at the Linux or macOS
  default path, or `$KICAD_SYMBOL_DIR`. verify.py parses both KiCad 7 and KiCad 8+ netlists
  and exits non-zero on any mismatch.
- `goa-console.pretty/` + `fp-lib-table` — project footprints (PTB0143/PTB0144 faders, Keystone 1287-ST tab, MF-R075 PTC),
  GENERATED by `tools/footprints.py` from the datasheet dimensions in its comments.

## Decisions made (do not silently change)
- Delta clone without mic stage (2026-10-22), replacing "no EQ, no trim": line gain −15 to +15 dB
  (centre detent 0 dB), Ø switch, switched HPF and 4-band EQ as the Delta (OPA1612), EQ IN, insert
  post-EQ (jumper for pre-EQ), ON switch with green LED (replaces MUTE), PAN switch, routing LEDs,
  PRE switch per aux pair (jumper: pre-fader / pre-EQ), direct out (aux 6 doubles as its level via
  DIR). Internal level stays 0 dBu; 4K7 summing stays.
- One 34-pin header per strip on a daisy-chained ribbon with crimped sockets (decided 2026-10-19;
  CN2 dropped).
- Bus = real Delta motherloom pinout (read from Delta ED3344C): GRP1-4 = SUB1-4 on pins 15/13/11/9,
  MIX R 17, MIX L 18, AUX6..1 on 20-25 (AUX1=24, AUX2=25), GND CANCEL 26, PFL 27, PFL DET 29,
  -V 30-31, +V 32-33, +48 V pin 34 not connected. Spares: 1,3,5,7,19. Even pins 2-16 = GND.
- Ground cancel: 10 Ω from strip AGND to pin 26; master summing amps reference that line.
  Each master summing amp is followed by a unity differential re-inverter (sum − GCANCEL).
  No tie from GCANCEL to master ground at the master end (2026-10-19; sim: a 22 Ω tie costs ~45 dB).
  Replaces SSL-style impedance-balanced bus (dropped unless the test jig says otherwise).
- Power on the ribbon (2 conductors per rail); heavy ground via a 6.3 mm spade per strip.
- MIX/SUB summing resistors 4K7 (master feedback must also be 4K7). AUX/PFL 22K.
  (10K would keep real Delta modules compatible; 4K7 is ~3 dB quieter.)
- Fader post-amp +10 dB (R38 2K2; omit for unity). Hot synths >~+12 dBu clip with fader at top.
- Channel path is non-inverting (tip = hot). Master summing inverts → master must re-invert once.
- Routing switch off = resistor's bus end to clean ground (Delta practice).
- AC coupling 220 µF NP + 47K on every node feeding the bus; JFET (J112) soft mute;
  separate logic rails +VL/−VL and logic ground GNDD joined to GNDA at one point (NT1).
- OPA1612 in noise-critical stages. NE5534 good for sub/aux summing (low current noise).
- 4 subs (with inserts), 6 aux (AFL on masters), 4 stereo returns, PFL only (no SIP), mute relay on mains.
- SSL bus compressor (Gyraf clone) as an external unit on the master insert.
- All balanced outputs use TI DRV134 (2026-10-19), Sense pins after a 10 µF NP per leg, mute
  relay after that. Replaced THAT1646, which went EOL (THAT memo 2026-09-01). The same memo
  kills THAT 2180/2181 (bus-compressor VCA, strip VCA option) and THAT 124x.
- VCA (decided 2026-10-19): Sound Semiconductor SSI2162 for the bus compressor (sidechain
  rescaled 6.1 → 33 mV/dB; THAT2181 backorder route rejected) and as a plug-in module for the
  strip VCA option.

## Verified so far
- Fresh channel-strip netlist check (2026-10-20): 313 pin entries, 0 mismatches or
  unexpected pins. check_fp: 103 parts, every symbol pin on a footprint pad.
- Strip placement check (KiCad 10.0.7, 2026-10-20): 109 footprints including six mounting
  holes, 0 tracks/vias/zones, 0 schematic-parity issues; no clearance, courtyard, hole or
  outline errors. DRC reports 219 expected unconnected items and 157 silkscreen warnings.
- KiCad 10.0.7 ERC, --severity-all: 0 errors, 0 warnings (2026-10-19).
- Master: netlist 2991 pins / 0 mismatches, check_fp 1062 parts / 0 problems, ERC 0 violations.
- Power-on mute (`sim/mute.cir`): closes 2.8 s after power-up, opens ~2 ms after either rail drops
  below ~14 V, full re-arm after any fault longer than ~10 ms.
- ngspice: 0 dBu in → PRE 0 dBu, POST +9.9 dBu, pan centre −6 dB, mute ≈ 86 dB, LF −3 dB 1.1 Hz.
- Delta-clone sims (2026-10-22, `sim/gain_stage.cir`, `sim/delta_eq.cir`, `sim/strip_v4.cir`): gain −15…+14.8 dB,
  0 dB at the detent; HPF (unity Butterworth) −3 dB 87 Hz; EQ HF ±11.5 dB @12k, HI-MID ±14.6 dB 670 Hz–10.5 kHz,
  LO-MID ±14.7 dB 148 Hz–2.3 kHz (Q 1.44), LF ±14.3 dB @54 Hz; flat ±0.16 dB, in phase; 0 dBu in → PRE 0 dBu.
  PRE noise −105.2 dBu EQ bypassed, −97.2 dBu EQ in (resistor noise; op-amp choice irrelevant).
- Bus noise (OPA1612, 24 ch routed): −97.6 dBu with 10K, −100.4 dBu with 4K7 (20 Hz–20 kHz).
